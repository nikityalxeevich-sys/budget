# Мой бюджет

Сайт для двоих: общий семейный бюджет, который правите вы оба, и личный бюджет у каждого. Работает на iPhone как приложение, в том числе без интернета: изменения сохраняются на телефоне и отправляются, когда появляется связь.

Всё бесплатно: хостинг на GitHub Pages, база и вход на Firebase (тариф Spark).

## Шаг 1. Firebase: проект и вход

1. Откройте console.firebase.google.com, войдите аккаунтом Google и нажмите «Create a project». Название любое, например `budget`. Аналитику (Google Analytics) можно отключить.
2. Слева выберите Build → Authentication → «Get started». Во вкладке «Sign-in method» включите «Email/Password» (первый переключатель, без «Email link») и сохраните.
3. Откройте вкладку «Users» → «Add user». Создайте два пользователя: почта и пароль для каждого из вас. Эти почты и пароли будут вашими логинами на сайте.
4. По желанию: вкладка «Settings» → «User actions» → снимите галочку «Enable create (sign-up)». Тогда никто посторонний не сможет завести себе аккаунт.

## Шаг 2. Firebase: база и правила

1. Слева Build → Firestore Database → «Create database». Режим «Production», регион ближайший, например `eur3` (Европа).
2. Откройте вкладку «Rules». Удалите всё и вставьте содержимое файла `firestore.rules`. Вместо `ПОЧТА_1@gmail.com` и `ПОЧТА_2@gmail.com` впишите две почты из шага 1, строчными буквами. Нажмите «Publish».

Эти правила дают общий бюджет только двум указанным почтам, а личный бюджет каждому только самому себе.

## Шаг 3. Firebase: настройки для сайта

1. Нажмите на шестерёнку рядом с «Project Overview» → «Project settings».
2. Внизу, в блоке «Your apps», нажмите значок `</>` (Web). Название любое, хостинг Firebase подключать не нужно.
3. На экране появится блок `const firebaseConfig = { ... }`. Скопируйте значения в файл `config.js`: `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`. Эти значения не секретные.

## Шаг 4. GitHub: выложить сайт

1. На github.com нажмите «New repository». Название, например, `budget`, видимость любая.
2. Нажмите «uploading an existing file» и перетащите все файлы из папки сайта (`index.html`, `app.js`, `sw.js`, `config.js`, `manifest.webmanifest`, три `.png`, `firestore.rules`, `README.md`). Нажмите «Commit changes».
3. Откройте Settings → Pages. В блоке «Branch» выберите `main` и папку `/ (root)`, нажмите «Save».
4. Через минуту-две сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/budget/`.
5. Если при входе будет ошибка про домен, в Firebase откройте Authentication → Settings → Authorized domains и добавьте `ВАШ_ЛОГИН.github.io`.

## Шаг 5. iPhone

1. Откройте адрес сайта в Safari, при интернете. Войдите почтой и паролем.
2. Нажмите «Поделиться» → «На экран „Домой“». На экране появится значок.
3. Откройте приложение с этого значка один раз при интернете и подождите несколько секунд: оно скачает всё нужное.
4. Дальше открывается и без интернета. Цифры, внесённые офлайн, уйдут в базу, как только появится связь. Если второй человек правил то же самое поле, останется последнее изменение.

То же самое делает и второй человек со своего телефона.

## Как обновлять сайт

Если меняете любой файл сайта, в `sw.js` увеличьте число в строке `VERSION` (например, `budget-v2`). Тогда телефоны скачают новую версию при следующем открытии.

## Что где хранится

- Семейный бюджет: `families/main/budget` в Firestore, доступ только двум почтам из правил.
- Личный бюджет: `users/<код пользователя>/budget`, доступ только владельцу.
- Бесплатного лимита Firebase (50 тысяч чтений и 20 тысяч записей в день) семье хватает с большим запасом.
